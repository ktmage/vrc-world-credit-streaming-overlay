# Code of Conduct

English | [日本語](./CODE_OF_CONDUCT.ja.md)

## Our Standards

This project is a small technical project for a streaming overlay. Keep discussion focused, practical, and respectful.

Good participation includes:

- Treating other people with patience and courtesy.
- Giving technical feedback that is specific and actionable.
- Assuming good intent while still being clear about bugs, risks, and disagreements.
- Respecting maintainers' time and project scope.
- Avoiding personal attacks, unwanted attention, or disruptive behavior.

## Project Scope

This repository is an unofficial VRChat-related tool. Do not present it as an official VRChat product, and do not use project spaces to request or share account credentials, private user data, or ways to bypass VRChat rules.

## Reporting Problems

If you see behavior that makes the project space difficult to use, contact the maintainer through the repository issue tracker or the contact method listed in the project profile.

When reporting, include:

- What happened.
- Where it happened.
- Links or screenshots if available.
- Whether immediate maintainer action is needed.

## Enforcement

Maintainers may edit or remove comments, close issues, limit participation, or block access when needed to keep the project usable and focused.

Enforcement decisions should be proportionate, documented when practical, and based on the behavior's impact on the project.
